Hospital Appointment Booking System

Overview
A simple web application that allows users to book doctor appointments online, reducing waiting time and improving convenience.

Features
View doctors and specializations
Book appointments
Input validation
Working hours restriction (9 AM – 6 PM)
View and clear appointments
Data stored in local storage

Technologies
HTML, CSS, JavaScript

Usage
Enter patient details
Submit the form
View booked appointments

Future Improvements
Add backend & database
User login system
Notifications
